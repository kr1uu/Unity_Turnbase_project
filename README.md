# Turn-Based RPG - Utility AI

Đồ án tốt nghiệp phát triển game **Turn-Based RPG** trên **Unity 6**, tập trung nghiên cứu và xây dựng hệ thống **AI Utility Scoring**, **Threat System**, cùng với **Custom Tool** hỗ trợ quản lý dữ liệu trong Unity.

---

# Giới thiệu

Đề tài hướng đến việc xây dựng một trò chơi nhập vai chiến thuật theo lượt (Turn-Based RPG) có thể chơi được, đồng thời nghiên cứu và áp dụng mô hình **Utility AI** nhằm giúp kẻ địch đưa ra quyết định linh hoạt hơn so với các mô hình AI truyền thống như Rule-Based hay FSM.

Ngoài hệ thống chiến đấu, dự án còn xây dựng các công cụ (Custom Tool) hỗ trợ quản lý dữ liệu nhân vật, kỹ năng, NPC, nhiệm vụ và vật phẩm bằng cơ sở dữ liệu **SQLite**, giúp việc phát triển và mở rộng game trở nên thuận tiện hơn.

---

# Các chức năng chính

## Hệ thống chiến đấu

- Cơ chế chiến đấu theo lượt (Turn-Based)
- Thứ tự hành động dựa trên chỉ số Speed
- Hệ thống kỹ năng
- Hệ thống hiệu ứng trạng thái (Status Effects)
- Tính toán sát thương
- Điều kiện thắng/thua

## Hệ thống AI

- Utility Scoring System
- Threat System
- Utility Profile
- Lựa chọn mục tiêu thông minh
- Nhiều phong cách AI:
  - Aggressive
  - Assassin
  - Healer
  - Debuffer
  - Captain
  - Shielder
  - Nemesis
  - Oldguard

## Hệ thống Gameplay

- Story Scene
- Battle Scene
- NPC
- Hệ thống nhiệm vụ (Quest)
- Party Management
- Inventory
- Equipment
- Shop
- Save / Load

## Quản lý dữ liệu

- SQLite Database
- Scriptable Object
- Custom Editor Tool
- Kiến trúc hướng dữ liệu (Data-driven)
